## Протокол агента

Когда агент подключается к сессии разработки:

1. Прочитать эту директорию (dev/) для контекста проекта
2. Прочитать `ARCHITECTURE.md` — понимание проектирования системы
3. Прочитать `COMPONENT-INVENTORY.md` — каталог файлов
4. Прочитать `SPEC.md` — технические контракты реализации
5. Прочитать `STACK-SUPPORT-ANALYSIS.md` — если работа связана с изменением стеков
6. Прочитать `PRODUCT-VISION.md` — стратегическое направление

**Правило:** Вся активная информация о проекте хранится в `dev/`. Не искать контекст по репозиторию — начинайте отсюда.
